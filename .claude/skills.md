# UniPass Mobilidade — Skills

Este documento define as competências esperadas ao trabalhar neste projeto.

---

## Backend Development

Tecnologias:

- Node.js
- Express (ou framework equivalente)
- PostgreSQL

Competências:

- Construção de APIs REST
- Autenticação com JWT
- Modelagem de banco de dados relacional
- Implementação de filas e jobs assíncronos
- Estruturação de arquitetura em camadas

---

## Mobile Development

Tecnologia:

React Native

Competências:

- Construção de aplicativos multiplataforma
- Integração com APIs REST
- Leitura de QR Code
- Persistência local com SQLite
- Sincronização offline

---

## Web Development

Tecnologia:

React.js

Competências:

- Construção de dashboards administrativos
- Gerenciamento de estado
- Integração com APIs
- Componentização de interfaces

---

## Data Sync

Competências:

- Sincronização offline-first
- Estratégias de consistência eventual
- Gerenciamento de filas de eventos
- Reconciliação de dados após reconexão

---

## System Design

Competências:

- Arquitetura baseada em API
- Separação entre frontend, mobile e backend
- Escalabilidade de serviços
- Design de sistemas distribuídos simples

---

## Product Understanding

Compreensão do domínio:

- Transporte estudantil
- Controle de matrículas
- Pagamentos recorrentes
- Validação de acesso ao transporte
